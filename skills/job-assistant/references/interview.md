# interview：面试准备与模拟

根据公司/岗位找到 job ID 和 `applied_revision`，优先使用那一版的 JD、评估、简历及话术。没有提交记录时可准备练习，但明说“尚未确认实际投递版本”，不能默认最近草稿已被面试官读过。

1. 只补问尚不清楚的轮次、形式、时间和已知面试官角色；不搜私人信息。
2. 读取 profile.md 的真实事实和本次申请事件、之前的面试记录。旧稿与新确认事实冲突时明确列出差异，不教用户继续讲已知不实口径。
3. 若有搜索能力，核实公司官网、相关业务与公开岗位信息，逐条附原页链接和查阅日期。搜索摘要只是线索，未读原页的标“待核实”；不用用户履历或联系方式做查询词。
4. 按 JD 和上轮反馈挑 3–5 个相关 STAR：背景、本人职责、行动、结果、预判追问。细节缺失用待确认项，不补编数据。
5. 覆盖项目深挖、协作冲突、真实求职动机、岗位差距；只有用户确实转型才准备转型问题。缺口答法为承认边界、邻接证据、真实的补充计划。
6. 反问聚焦本岗位职责、成功标准、团队协作和用户关心的约束，不问官网已有明确答案的泛泛问题。
7. 用户要求模拟时逐题进行，按真实事实反馈；不自行替用户答完整轮次。

准备包放在 `WORKSPACE/applications/JOB_ID/interviews/<轮次>-<日期>-<未占用版本>.md`，不写进已投简历版本。复盘按时间追加，新事实同轮回写档案。研究不可用时仍可完成基于 JD 的准备，明确公司调研缺口。
